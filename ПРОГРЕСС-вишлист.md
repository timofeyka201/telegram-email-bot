# Вишлист — что сделано и что осталось

Коммиты `377e099` и `442b475`, ветка `claude/tinder-marketplace-1688-4cvwfd`,
уже в GitHub. Сборка (`npm run build`) и проверка типов (`npx tsc --noEmit`)
проходят. Проверено запросами к серверу и в браузере — вишлист готов,
осталось только выложить.

## Сделано и проверено

Вишлист перестал быть второй полкой избранного и переехал на сервер.
У каждого вошедшего один список с коротким кодом вида **SW-K7QM4X**.

| Что просили | Где живёт |
|---|---|
| делиться списком | `/wishlist` — кнопки «Поделиться» (системное меню телефона) и «Копировать» |
| найти вишлист знакомого по ID | поле поиска на `/wishlist`; принимает `K7QM4X`, `sw-k7qm4x` и целую ссылку |
| бронировать подарки друзей | `/wishlist/КОД` — «Беру на себя»; занятое чужим показано как «Занято · Имя» |
| описание к желанию | поле «Пожелание» у каждой карточки, видно гостям |
| свои карточки (не только из Swiper) | «+ Добавить своё желание»: ссылка, фото, название, цена; кнопка «Заполнить» вытягивает их со страницы магазина |

Дополнительно: вкладка «Я дарю» — памятка о том, что вы кому-то пообещали;
настройки списка (название, подпись для гостей, выключатель доступа по ссылке);
вишлист стал четвёртым пунктом нижнего меню.

**Владелец брони не видит.** Это проверено отдельно: в ответе сервера владельцу
слова `reserved` нет вовсе, и время изменения списка бронь не трогает.

Проверено запросами к запущенному приложению (три учётные записи):
повторное добавление одного товара не плодит дубликаты; `javascript:` в ссылке
не сохраняется; перебронировать и снять чужую бронь нельзя (409); свой список
по коду перенаправляет к себе; удалённое владельцем желание само исчезает из
памятки дарителя; закрытый доступ отдаёт 403; гость список видит, а бронировать
не может (401); несуществующий код — 404, кривой — 400.
Разбор страницы магазина проверен на семи видах разметки (Open Graph,
twitter-карточка, микроданные, только `<title>`, пустая страница, мусор в цене,
`javascript:` в картинке). Защита от похода во внутреннюю сеть проверена:
`127.0.0.1`, `localhost` и `169.254.169.254` отклоняются.

Проверка в браузере (390 и 320 px, глазами владельца, друга и не вошедшего)
прошла: 28 утверждений, все сошлись. Единственная ошибка в консоли —
заблокированный в песочнице шрифт Google; на боевом сервере его нет.
По итогам этой проверки поправлены четыре вещи, которые видно только глазами:
порядок блоков (поиск чужого списка заслонял собственный), значок в меню
показывал заниженное число желаний, «но не Аля» вместо падежа и заглушка в
поле кода, набиравшаяся капсом.

## Осталось по вишлисту

**Выложить на сервер**: `su - swiper -c 'cd ~/app && swiper-update'`.

## Осталось по прошлым задачам (не забыл)

* **Resend**: домен `swipers.ru` всё ещё «Pending». Пока он не Verified,
  подтверждение почты приходит только вам — а без подтверждения теперь никто
  не войдёт. Как проверится: `MAIL_FROM=Swiper <no-reply@swipers.ru>` и перезапуск.
* Прогнать `scripts/shrink-images.mjs`, затем `scripts/cache-images.mjs --limit 500`
  на снимке каталога (5000 карточек, ~10 000 фотографий).
* Нарастить каталог до ~20 000 (`--budget 400`) и добавить две записи в cron:
  импорт в 04:30, кэш фотографий в 05:00.
