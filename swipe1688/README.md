# Свайпы 1688

Витрина товаров с 1688 с механикой Tinder: свайп вправо — нравится, влево — мимо,
вверх — сразу в корзину. Тап по карточке открывает подробности: галерея, описание,
характеристики, отзывы, оптовые цены и поставщик.

## Быстрый старт

```bash
cd swipe1688
npm install
cp .env.example .env.local        # и вписать BHAPI_TOKEN
npm run dev                       # http://localhost:3000
```

Без токена приложение открывается и полностью работает на встроенной
демо-подборке (кнопка «Демо» на главной) — удобно смотреть UX, не тратя запросы к парсеру.

## Что умеет

**Главная — парсинг и лента**
- Два режима: «По слову» (поиск) и «По ссылкам» (вставить ссылки на товары 1688 или их ID,
  можно списком — до 40 за раз, запросы идут параллельно по 5).
- Быстрые чипы с популярными категориями.
- Колода из трёх карточек с физикой перетаскивания, штампами решения и поворотом.
- Тап по левому/правому краю карточки листает фото, тап по центру открывает подробности.
- Клавиатура: `←` мимо, `→` нравится, `↑` в корзину, `Enter`/`Space` подробности, `Backspace` вернуть.
- Кнопка «вернуть карточку» отменяет последнее решение вместе со всеми его последствиями.
- Лента дозагружается сама, когда до конца остаётся меньше пяти карточек.

**Карточка товара**
- Галерея со снапом, миниатюрами и счётчиком.
- Цена в рублях и юанях, таблица оптовых порогов, варианты (SKU), минимальный заказ.
- Вкладки: описание, характеристики, отзывы (с фото покупателей).
- Блок поставщика, ссылка на оригинал на 1688.
- Если товар пришёл из выдачи поиска без описания и отзывов — они догружаются по ссылке.

**Избранное и корзина**
- Избранное — плитка с быстрым добавлением в корзину.
- Корзина считает цену по оптовому порогу для текущего количества, показывает итог
  в рублях и юанях, курс редактируется вручную.
- «Скопировать заказ» кладёт в буфер список с количествами, ценами и ссылками.

**Вовлечение**
- Дневная цель в 20 карточек с кольцом прогресса.
- Счётчик серии лайков подряд.
- Тактильная отдача на свайпах, тосты, экран «карточки закончились» с итогами сессии.
- Всё состояние (колода, позиция, избранное, корзина, статистика) переживает перезагрузку.

## Стек

Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · Framer Motion · Zustand.
Состояние — в `localStorage`, без базы и без авторизации: для MVP этого достаточно,
а добавить бэкенд можно, не трогая UI.

## Как устроена работа с парсером

```
src/lib/bhapi.ts       клиент API: токен, таймауты, кэш, разбор ошибок
src/lib/normalize.ts   приведение ответа к модели Product
src/lib/types.ts       модель данных
src/lib/demo.ts        встроенная подборка для работы без токена
src/app/api/parse      POST: собрать ленту (поиск / ссылки / демо)
src/app/api/item       GET:  полная карточка по ссылке
src/app/api/img        прокси картинок (alicdn отдаёт их только со «своим» Referer)
src/app/api/placeholder  локальные SVG-заглушки вместо битых фото
src/app/api/debug      сырой ответ парсера — для сверки схемы
```

Токен читается только на сервере и в браузер не уходит: фронт ходит в свои `/api/*`.

### Про эндпоинты

Подтверждён один эндпоинт — тот, что был в задании:

```
GET https://bhapi.ru/1688/api/v1/item/by-url?url=...
Header: X-API-Token: <токен>
```

На нём построен режим «По ссылкам» — он работает гарантированно.

Точный путь для поиска по ключевому слову в задании не назывался, поэтому
`search()` в `src/lib/bhapi.ts` перебирает пять правдоподобных вариантов
(`/item/search`, `/search`, `/items/search`, `/search/items`, `/item/by-keyword`)
и запоминает сработавший. Если у парсера поиск называется иначе или его нет,
режим «По слову» вернёт понятную ошибку и предложит вставить ссылки. Правится
это одной строкой в списке `SEARCH_CANDIDATES`.

### Про схему ответа

Точная структура JSON тоже не была зафиксирована, а из окружения разработки
`bhapi.ru` недоступен, поэтому нормализация в `normalize.ts` не привязана к
жёстким путям: она обходит JSON в ширину и выбирает первое правдоподобное
значение по смыслу ключа (`title|subject|name|...`, `images|imgs|pics|...`,
`price|priceRange|...`, `reviews|comments|feedback|...` и так далее). Это
переживает переименования полей и разные формы обёрток (`data`, `result`, `item`).

Чтобы свериться с реальной схемой и при желании ужать маппинг под конкретные поля:

```bash
curl 'http://localhost:3000/api/debug?path=/item/by-url&url=https://detail.1688.com/offer/123456789.html' | jq
```

## Деплой

Vercel: Root Directory — `swipe1688`, в переменные окружения добавить `BHAPI_TOKEN`.
Корневой `vercel.json` репозитория относится к Python-боту и на этот проект не влияет.

## Ограничения MVP

- Нет авторизации и серверного хранилища: избранное и корзина живут в браузере.
- Корзина не оформляет заказ — она собирает список и отдаёт его в буфер обмена.
- Курс юаня задаётся вручную, доставка и комиссии не считаются.
